## 學習動機：從「拆解者」的角度看金融
我對金融數據如何從原始表格轉化為圖表充滿好奇。我不滿足於只當一個現成軟體的使用者，我渴望成為底層邏輯的「拆解者」。因此，我計畫透過 Python 實作從數據抓取到指標生成的完整流程，深入鑽研 MA、RSI 與布林通道的數學原理。

## 🛠️ 實作內容與規劃
我將本計畫分為四個主要階段：
1. **資料擷取**：利用 `yfinance` 自動取得歷史股價。
2. **邏輯演算**：以 `Pandas` 清洗數據，手寫實作技術指標數學公式。
3. **視覺化呈現**：使用 `Matplotlib` 將數值轉化為直觀圖表。
4. **系統化整合**：達成輸入代號即可自動生成分析結果。

## 📈 核心技術指標實作
* **移動平均線 (MA)**：透過 `rolling` 函數設定滑動視窗，觀察趨勢。我發現在擷取時間過短時會出現「邊界缺失」現象，這讓我學會處理數據中的 NaN 值。
* **相對強弱指標 (RSI)**：手寫漲跌幅計算邏輯。我也發現自己的算法與主流平台（如 TradingView）存在微小差異，這引發我對平滑算法（SMA vs EMA）的深入研究。
* **布林通道**：利用標準差定義價格的「正常波動區間」。
